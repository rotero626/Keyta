Keyta support

Most problems are about the app finding your server. Start with the questions below.

Contact us

Email: keytasupport@gmail.com

Please tell us which device you use (iPhone, iPad, Mac or Apple TV), your version of Keyta and of Keyta Server, and whether the server runs on Windows or Mac. Do not send us your server token or your TMDB key.

Questions

Keyta says it can’t find my server
  1. Check that Keyta Server is running on your computer. Look for its icon in the Windows notification area or the Mac menu bar, and choose Open Keyta Setup. If the page opens, the server is up.
  2. Make sure your device and the computer are on the same Wi-Fi or network. Guest networks and some mesh or router settings (“client isolation”) stop devices seeing each other. A VPN on the device can also get in the way, so try turning it off.
  3. Allow Local Network access to Keyta. On iPhone and iPad: Settings, Privacy & Security, Local Network, then switch Keyta on. On Mac, also allow it for Keyta Server in System Settings, Privacy & Security.
  4. On Windows, the firewall must allow Keyta Server on private networks (ports 8097 and 8497). The installer offers to add the rules. If you skipped them, run the installer again, or allow the app when Windows asks. Your network must be set to Private, not Public.
  5. Make sure the computer is awake. A sleeping computer cannot be found.
  6. Still no luck? Enter the address by hand. The setup page shows your computer’s address in large type at the top. In Keyta, choose to add a server by address and type it in (it looks like 192.168.1.20:8097).
My device found the server but won’t connect

The first time, you must approve the device on the setup page on the computer: compare the 4-digit code shown on the device with the one on the page, then choose Approve. The setup page opens only on the computer that runs Keyta Server.

How do I watch away from home?

Playing away from home is part of Keyta Plus. Your server needs to be reachable from the internet:

  1. On the setup page, open the Sharing section and switch on remote access.
  2. Keyta Server asks your router to open its port automatically (NAT-PMP or UPnP). If it works, the page shows the status as mapped, with your public address.
  3. If the router refuses, forward the port by hand: in your router’s settings, forward the TCP port shown on the setup page (the secure remote port, 8497 by default) to your computer’s address on your home network, then choose manual mode in Sharing. Give the computer a fixed address on the router first, so the forward keeps working.
  4. Some internet providers put many customers behind one shared address (CGNAT) or block incoming connections. In that case port forwarding cannot work. Ask your provider for a public address.

Friends you invite play your library, home or away, with a single-use invite link valid for 7 days. Creating invites is part of Keyta Plus.

How do I get a TMDB key?

Keyta Server uses a free key from TMDB (The Movie Database) to show posters and descriptions. It is free for personal use.

  1. Create a free account at themoviedb.org/signup and confirm your email.
  2. Open themoviedb.org/settings/api (or click your picture, then Settings, then API).
  3. Choose Create (or Request an API Key), then Developer, and accept the terms.
  4. On the form, set the type of use to Personal, and give any application name, a web address such as http://localhost and a one-line summary.
  5. Copy the API Read Access Token (the long one) or the API Key (32 characters). Paste it into the TMDB step on the setup page and choose Check and save.

The key stays on your computer and is not shown again after saving. Your devices use the server’s key automatically.

Posters and descriptions are missing

This almost always means the TMDB key is missing or wrong. Open the setup page, go to the TMDB step and use Check and save with a fresh key (see above).

I bought Keyta Plus but it isn’t active

In Keyta, open Settings, then Keyta Plus, and choose Restore Purchases. Make sure you are signed in to the same Apple account you bought with. Plus belongs to your Apple account, not to a Keyta account. See the subscription terms to cancel or manage it.

Will it work on Apple TV and Mac?

Yes. Keyta runs on iPhone, iPad, Mac and Apple TV. Google Cast is available on iPhone and iPad only, and joining a friend’s server with an invite link is not available on Apple TV.

Where is my data, and how do I delete it?

On your own server and your own devices. See the privacy policy.

Windows or macOS warns me when I open Keyta Server

Keyta Server is not yet signed with a paid certificate, so Windows SmartScreen and macOS Gatekeeper warn about it. Follow the steps on the Keyta Server page (More info, then Run anyway on Windows; right-click, then Open on Mac).
