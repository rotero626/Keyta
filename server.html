Keyta Server

Keyta Server is a free app that runs on the Mac or Windows PC that holds your media. The Keyta app on your iPhone, iPad, Mac or Apple TV connects to it.

Download for Windows

Installer (KeytaServer-Windows-Setup.exe).

No installer: ZIP version

macOS

Download for Mac

Disk image (KeytaServer-macOS.dmg), works on Apple silicon and Intel Macs.

The current version and its release notes are on the release page.

System requirements

  • Windows: Windows 10 (version 1809) or later.
  • Mac: macOS 15 or later.
  • A computer that stays on and connected to your home network while you watch.
  • Your films and shows stored on that computer or on a drive it can reach, including mapped network drives.
  • A free TMDB key for posters and descriptions. The setup page walks you through getting one.
  • The Keyta app on iPhone or iPad (iOS 18 or later), Mac (macOS 15 or later) or Apple TV (tvOS 18 or later).

Install on Windows

  1. Run KeytaServer-Windows-Setup.exe. It installs to Program Files and can add a desktop shortcut, start Keyta Server when you sign in, and add Windows Firewall rules so your phone can reach it. Windows asks for administrator permission for this.
  2. The installer is not signed with a paid code-signing certificate, so Windows may say “Windows protected your PC”. Choose More info, then Run anyway.
  3. Finish with Open Keyta Server. Your browser opens the setup page, and a small eye icon appears in the notification area.

Install on Mac

  1. Open KeytaServer-macOS.dmg and drag Keyta Server into Applications.
  2. The first time, right-click the app and choose Open, then Open again. The app is not notarised by Apple, so a plain double-click is refused the first time. If the Open button is missing, go to System Settings, Privacy & Security, and choose Open Anyway.
  3. Allow Local Network access when macOS asks. This is how your devices find the Mac.
  4. The setup page opens in your browser. Keyta Server lives in the menu bar and has no Dock icon.

Set it up

  1. On the setup page, add the folders that hold your films and shows.
  2. Add your free TMDB key. The page shows the steps.
  3. Open Keyta on your iPhone, iPad, Mac or Apple TV. It finds your server by itself. Compare the 4-digit code on the device with the one on the setup page, then choose Approve.

The setup page can only be opened from the computer running Keyta Server. Other devices cannot see it.

Stuck? See Support.

Uninstall

On Windows, remove it in Settings, Apps. The installer keeps your settings and paired devices unless you tick the box to delete them. On Mac, quit it from the menu bar and drag the app to the Bin.
